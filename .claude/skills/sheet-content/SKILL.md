# 시트 콘텐츠 작업

## 읽기·쓰기
- `core.sheet.Sheet().read(탭)` 로 전체를 읽어 스크래치에 json 으로 저장, 줄번호|수술부위|본문 앞 170자 로 압축본을 만들어 읽는다 (본문이 길어 한 번에 다 못 봄)
- **쓰기 직전에 머리글을 다시 읽어 열 위치를 확인** — 사용자가 열을 지우거나 옮기는 일이 잦다 (2026-10-14 로테이션 열 삭제)
- 쓰기는 `Sheet().write(탭, "F2", [[값], ...], text=True)` — 연속된 칸은 한 번에. 쓰기 전 길이·빈칸·분류 누락을 스크립트로 검사(dry run)하고 문제 0건일 때만 쓴다

## 본문(게시글)
- 150~450자, 말투를 줄마다 다르게(반말/존댓말/음슴체/질문 목록/경험담), 병원 이름은 본문에만 자연스럽게
- 같은 문장 틀 반복 금지 — 쓰고 나서 첫 문장이 겹치는지 검사

## 제목
- 본문 요약, **20자 이내**(공백 포함), 커뮤니티 말투 ("~궁금해요", "~고민ㅠ", "~하신 분?")
- 제목에 병원 이름 넣지 않음 (광고처럼 보임). 같은 제목 중복 검사

## 바비톡 주제 (앱: 커뮤니티 > 글쓰기 > '성형' 맨 위 항목 > 주제)
눈 / 코 / 지방흡입/이식 / 가슴 / 안면윤곽/양악 / 남자성형 / 기타
- 눈: 쌍수·눈재·소세지눈재·눈밑지·안검하수·눈매교정·트임·상안검·하안검
- 코: 코재·구축코재·기능코·루나코·매부리·복코·휜코·들창코·짧은코·낮은코·코끝·콧볼·비중격·비염·축농증
- 지방흡입/이식: 얼지흡·각종 지방이식 / 안면윤곽/양악: 광대·사각턱·윤곽3종·무턱·턱끝 / 기타: 각종 거상
- 본문에 남자 얘기가 중심이면 남자성형

## 일정 점검
- 폰별 글 수, 같은 날 같은 폰 두 번, 같은 폰 글 간격(일), 본문·제목 중복, 하루 건수 — 스크립트로 세어서 표로 보고
